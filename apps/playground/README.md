# react-data-import playground

An empty Vite + React 19 shell for now. RDI-9 turns it into the demo: drop an `.xlsx` or `.csv`, see `{ columns, data }`, map columns. It imports the library from `packages/react-data-import/src`, so it always matches the branch.

```sh
npm run dev -w playground
```

It isn't deployed yet. The Vercel project (root `apps/playground`) is created when the playground has something to show.
