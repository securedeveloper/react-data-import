# react-data-import

Import `.xlsx` and `.csv` files into React apps as `{ columns, data }` datasets. Built on [javascript-excel](https://github.com/securedeveloper/javascript-excel).

> **Status: planned.** This package is not usable yet. Version 0.0.1 only reserves the name. 1.0 is designed in [docs/api.md](https://github.com/securedeveloper/react-data-import/blob/main/docs/api.md) (decided 2026-11-16) and is being built: `importFile`, `useDataImport`, an unstyled `<DataImport>` drop zone and a headless `useColumnMapping`. Watch the [repository](https://github.com/securedeveloper/react-data-import) for the first prerelease.
