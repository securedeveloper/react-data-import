# react-data-import

Import `.xlsx` and `.csv` files into React apps as `{ columns, data }` datasets. Built on [javascript-excel](https://github.com/securedeveloper/javascript-excel).

> **Status: in development.** Version 0.0.1 on npm only reserves the name. 1.0 is designed in [docs/api.md](https://github.com/securedeveloper/react-data-import/blob/main/docs/api.md) (decided 2026-11-16). `importFile`, `previewFile`, `useDataImport`, an unstyled `<DataImport>` drop zone and a headless `useColumnMapping` are implemented on `main`. Watch the [repository](https://github.com/securedeveloper/react-data-import) for the first prerelease.
